Instagram Import

Open an Instagram profile or photo post. Read and preview the current photo, capture it, then advance Instagram yourself. Review the complete post before exporting.

1. Read a post

Manual reads never move the carousel. Open photo 1 in Instagram, read and capture it here, click Instagram’s next arrow, then read again. Automatic collection is optional.

Choose a loaded profile post

    This lists loaded photo-post links, not a complete account history. Scroll the profile and read it again to load more. Open a post, then return here and read its tab to capture it.
